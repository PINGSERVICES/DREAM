# Sté Dream Library - Medjez el Bab

Site web officiel de la Librairie Sté Dream à Medjez el Bab, Tunisie. Proposant des fournitures scolaires, bureautiques, informatique, jouets et cadeaux.

## Caractéristiques

- **Bilingue** : Français et Arabe avec support complet RTL (Right-to-Left).
- **Mobile Friendly** : Design réactif optimisé pour tous les écrans.
- **Espace Jeu** : Emplacement réservé pour un futur mini-jeu de navigateur mobile.
- **Socials** : Liens directs vers Instagram, Facebook, TikTok et Threads.

## Sources & Crédits

- **Images** : Photos réelles du magasin fournies par le client (sign.png).
- **Données** : Informations vérifiées à partir des profils officiels [@stedream1](https://www.instagram.com/stedream1/) et [Facebook](https://www.facebook.com/stedreamlibrary).
- **Généré par** : Claude Code.

## Développement

Ce projet utilise [Astro](https://astro.build/) avec Tailwind CSS.

### Prérequis

- Node.js (v22 ou supérieur recommandé)

### Installation

```bash
npm install
```

### Serveur de développement

```bash
npm run dev
```

### Build pour la production

```bash
npm run build
```

Le résultat sera dans le dossier `dist/`. Pour le déploiement sur GitHub Pages, le `base` est configuré sur `/DREAM`.
